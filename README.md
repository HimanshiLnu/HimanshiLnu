### 2. [NYC 311 Smart Complaint Explorer and AI Assistant](https://github.com/HimanshiLnu/NYC-311-Smart-Complaint-Explorer-With-AI-Assistance)
**PostgreSQL, Python, MCP, Chart.js**
- I cleaned the 2025 NYC 311 data and joined it with weather data in PostgreSQL.
- I built a dashboard on top of it with charts for borough, season, temperature and agency.
- I also built an MCP server so an AI assistant can query the same data.

### 3. [Algorithmic Trading Strategy for QQQ](https://github.com/HimanshiLnu/QQQ-Algorithmic-Trading-Strategy)
**Python, pandas, backtesting.py, yfinance**
- Team project with 3 other students for Analytics Programming.
- We built a rule-based strategy for the QQQ ETF. It starts with a moving average crossover and adds an RSI filter and risk rules.
- We tuned it on data from 2023 to April 2025 and tested it on the year after.

### 4. [Manhattan Residential Noise Complaints](https://github.com/HimanshiLnu/Manhattan-Noise-Complaints-Analysis)
**R, Shiny, Poisson regression**
- Team project with 1 other student for Computational Math and Stats.
- We studied when residential noise complaints happen in Manhattan using 2025 NYC 311 data.
- Complaints rise in the late evening and on weekends. A Poisson regression showed that hour, weekday and season are linked to complaint counts.
- We also built a Shiny dashboard for the results.

### 5. [NYC 311 Complaints Dashboard in Tableau](https://github.com/HimanshiLnu/NYC-311-Tableau-Dashboard)
**Tableau, Python, pandas**
- A project for Visual Design and Storytelling.
- I cleaned about 3.1 million NYC 311 complaints and joined them with daily weather data.
- I built a Tableau dashboard that shows complaints by month, season, borough and agency, and how fast they get resolved.
- I also looked at complaints with very long resolution times. About 14% took more than 5.5 days to close.
